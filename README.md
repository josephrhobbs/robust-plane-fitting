# Optimal Polynomial-Time Robust Plane Fitting

Technical report and associated Python code for developing a globally optimal, polynomial-time algorithm for robust plane fitting.

This repository explores the problem of __Robust Plane Fitting__ (RPF) to study convex formulations for problems in robust calibration and computer vision.  We define RPF as the determination of a "least-squares" plane under Gaussian noise and in the presence of outliers.

The technical report on convex formulations in robust plane fitting may be found at `report/plane-fitting.pdf`.
